# TitanicMLPredictor

## Before Running the model
Ensure you have installed **scikit-learn**, **pandas**, and **tensorflow**

## Running the model
Run **preprocess.py** first to ensure that a filtered form of the data exists.
Then run **model.py** to prepare, train, and evaluate the model. 
The accuracy seems to peak around 0.788 after trying both the sklearn and the tensorflow model.
